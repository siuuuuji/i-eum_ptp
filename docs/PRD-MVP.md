# 이음(i-eum) 한 달 파일럿 MVP PRD

## 1. 제품 한 줄 정의

시니어가 질문에 글이나 목소리로 답하며 삶의 기억을 쌓고, 허용한 기록과 가족의 일상을 연결된 가족끼리 안전하게 나누는 모바일 우선 PWA.

## 2. 이번 MVP의 목표

- 5~15명의 실제 사용자가 한 달 동안 주 3회 이상 접속할 수 있다.
- 시니어가 별도 설명 없이 오늘의 질문에 답하고 저장할 수 있다.
- 가족이 초대코드로 연결되어 서로 다른 기기에서 같은 데이터를 본다.
- 기록 공개 범위가 실제 서버 권한으로 보호된다.
- 가족 소식이 글과 기기 기본 음성으로 재생된다.

## 3. 핵심 사용자

1. 시니어: 큰 글자와 단순한 동선으로 질문에 답하고 자서전 진행을 확인한다.
2. 가족: 가족 공간에 참여해 소식을 남기고, 공개된 시니어 기록을 읽거나 듣는다.

## 4. 필수 사용자 흐름

### A. 가입과 가족 연결

회원가입 → 역할 선택 → 가족 공간 생성 또는 6자리 초대코드 입력 → 가족 홈 진입

### B. 기억 남기기

오늘의 질문 확인 → 글 입력 또는 음성 녹음 → `가족 공개/나만 보기` 선택 → 저장 → 진행률 갱신

### C. 가족 소식

가족 탭 → 짧은 소식 작성 → 등록 → 연결된 가족의 라디오 목록에 노출 → 읽어주기 실행

## 5. MVP 기능 범위

| 구분 | 포함 | 제외/후순위 |
|---|---|---|
| 계정 | 이메일 가입·로그인, 시니어/가족 역할 | 소셜 로그인, 보호자 대리 가입 |
| 연결 | 가족 생성, 초대코드 참여 | 여러 가족 동시 참여 |
| 기억 | 질문, 글 답변, 음성 녹음, 공개 범위 | AI 질문 추천, 자동 자서전 문장화 |
| 자서전 | 기록 수 기반 진행률, 목록·검색 | PDF 책 자동 편집·인쇄 |
| 가족 소식 | 글 등록, 목록, 브라우저 음성 읽기 | 예약 자동 재생, 카카오·문자 알림 |
| 미디어 | 10MB 이하 비공개 음성 | 영상편지 업로드 |
| 운영 | PWA, 모바일/데스크톱 반응형 | 앱스토어 등록, 결제 |

## 6. 데이터 및 권한 원칙

- 모든 데이터는 가족 ID로 분리한다.
- 가족 기록은 연결된 가족만 읽는다.
- `나만 보기` 기억은 작성자만 읽는다.
- 음성 파일은 비공개 저장소에 두고, 로그인한 같은 가족에게만 임시 재생 주소를 발급한다.
- 브라우저에 관리자 비밀키를 포함하지 않는다.

## 7. 파일럿 성공 지표

- 가입 완료율 80% 이상
- 질문 답변 저장 성공률 95% 이상
- 시니어 1인당 주간 기억 3개 이상
- 가족 1인당 주간 소식 2개 이상
- 가족 라디오 주간 재생 2회 이상
- 공개 범위 관련 사고 0건

## 8. 출시 전 체크

- 개인정보 수집·이용 동의 문구 확정
- 실제 시니어 2명 이상 사용성 테스트
- 계정 삭제 및 데이터 내보내기 운영 절차 준비
- Supabase 사용량과 음성 저장공간 매주 확인
- 테스트 종료 시 보존/삭제 여부를 참여자에게 재확인
