# 천리말랑 퀘스트보드

백락정령과 천리말랑이, 두 사람이 하나의 대시보드에서 할 일을 나누고 함께 해내는 웹앱입니다.
레퍼런스 일러스트 5장을 화면의 상태 표현으로 끌어와, 지금 숲이 어떤 상황인지를 그림으로 먼저 보여줍니다.

접속 주소: `/malang` (로컬 개발 시 `http://localhost:5173/malang.html`)

## 두 사람

| | 백락정령 | 천리말랑이 |
| --- | --- | --- |
| 역할 | 숲의 인도자. 주로 일을 맡깁니다. | 숲을 지키는 왕관. 맡은 일을 해냅니다. |
| 강조색 | 금빛 `#cfa95f` | 장밋빛 `#d9899f` |
| 완료 권한 | 자기 두루마리의 일만 | 자기 두루마리의 일만 |

일을 맡기는 건 두 사람 다 할 수 있지만, 완료 체크는 **그 일을 맡은 사람만** 누를 수 있습니다.
백락정령이 천리말랑이의 일을 대신 완료 처리할 수는 없습니다.

## 대시보드 장면 (레퍼런스 ↔ 상태)

대시보드 맨 위의 무대는 보드 상태에 따라 레퍼런스 그림이 교차 페이드로 바뀝니다.

| 상태 | 조건 | 레퍼런스 | 화면 문구 |
| --- | --- | --- | --- |
| **완료** | 방금(8초 이내) 일을 하나 끝냈을 때 | 2번 — 말랑이가 고블린을 삼키는 장면 | “와아아앙!!” |
| **모두 완료** | 남은 일이 하나도 없을 때 | 5번 — 서로 기대어 웃는 장면 | “다 했다…!” |
| **기한 초과** | 기한이 지났는데 아직 안 끝낸 일이 있을 때 | 3번 — 말랑이의 볼을 누르는 장면 | “마아알라앙…!!” |
| **1시간 경과** | 맡긴 지 1시간이 지나도록 그대로인 일이 있을 때 | 1번 — 손끝으로 콕 찌르는 장면 | “콕. 콕.” |
| **고요한 숲** | 급한 일도 늦은 일도 없을 때 | 1번 (차분한 문구) | “오늘은 평화롭네.” |

우선순위는 위 표의 순서 그대로입니다. 마지막 일을 끝내면 **완료 → 모두 완료**로 자연스럽게 이어집니다.
알림 상태(기한 초과·1시간 경과)는 천리말랑이의 일을 먼저 집어 보여줍니다.

한 시간을 기다리지 않고도 확인할 수 있도록, 무대 아래 **장면 미리보기** 줄에서 다섯 장면을 바로 눌러 볼 수 있습니다.
미리보기 중에는 “↺ 지금 상태로” 버튼으로 실제 상태에 돌아옵니다.

## 캘린더 — 여정 기록

- 머리그림은 4번 레퍼런스(구름 위 ‘상위 1%의 성’)입니다.
- 월요일 시작의 주간 보기이며, `← 지난주 / 다음주 →`로 주를 옮깁니다.
- 각 날짜 칸에 **백락정령과 천리말랑이가 그날 완료한 일**이 이름·시각과 함께 함께 쌓입니다. 색 띠로 누구의 일인지 구분합니다.
- 기한이 그날이었는데 아직 못 끝낸 일은 붉은 띠로 따로 표시됩니다.
- 아래 요약에 주간 합계, 사람별 개수, 기한 안에 끝낸 비율, 주간 목표(12개) 진행률이 나옵니다.

## 레퍼런스 그림을 화면에 스며들게 하는 방식

`src/malang/components/RefArt.tsx` + `.mq-art*` 규칙이 담당합니다. 그림을 그대로 붙이지 않고 세 겹을 씁니다.

1. **방사형 마스크** — `mask-image: radial-gradient(...)`로 네 모서리를 서서히 투명하게 흘려보내 테두리를 지웁니다.
2. **불투명도** — 기본 `opacity: 0.96`으로 살짝 낮춰 배경의 빛과 섞이게 합니다.
3. **덧칠(wash)** — 위·아래·좌우 가장자리에 배경색(`--ivory` 계열) 그러데이션을 얹어 화면에서 번져 나온 것처럼 잇습니다.

그 위에 `.mq-stage__scrim`이 글자가 놓이는 자리에만 아주 옅은 빛을 깔아 가독성을 지킵니다.
좁은 화면(≤620px)에서는 잘라내는 대신 그림을 온전히 펼치고 글을 아래로 내립니다.

## 색과 부품

레퍼런스의 아이보리·금빛 자수·말랑이 볼의 장밋빛·수정 라일락을 그대로 토큰으로 옮겼습니다
(`src/malang/theme.css`의 `:root`). 버튼은 금빛 그러데이션에 빛이 스치는 효과, 카드는 반투명 유리에 금색 실선,
배경에는 빛가루가 천천히 떠오릅니다. `prefers-reduced-motion`을 켠 사용자에게는 모든 움직임을 멈춥니다.

## 데이터와 동기화

- 모든 기록은 브라우저 `localStorage`(`malang.board.v1`)에 저장됩니다. 서버는 쓰지 않습니다.
- 같은 브라우저의 여러 탭·창은 `BroadcastChannel`(미지원 브라우저는 `storage` 이벤트)로 즉시 동기화됩니다.
- **보는 사람(역할)은 `sessionStorage`에 저장**되므로 탭마다 다르게 둘 수 있습니다.
  창을 두 개 띄워 하나는 백락정령, 하나는 천리말랑이로 두면 두 사람이 주고받는 흐름을 그대로 볼 수 있습니다.
- 기기가 다르면 기록은 공유되지 않습니다. 실제 두 사람이 각자 기기에서 쓰려면 서버/DB가 필요합니다(아래 참고).

## 파일 구조

```
malang.html                     # 진입 HTML (Vite 멀티 페이지)
public/malang/                  # 레퍼런스 일러스트 5장(WebP) + 아이콘
src/malang/
  main.tsx  App.tsx  theme.css  types.ts
  lib/
    store.ts     # 보드 상태 + localStorage + 탭 간 동기화
    scene.ts     # 보드 상태 → 레퍼런스 장면 판정
    time.ts      # 기한/경과/주간 계산
    persona.ts   # 인물 색, 한국어 조사 처리
    seed.ts      # 첫 방문용 예시 기록
  components/    # RefArt, SceneStage, TaskCard, TaskColumn, Composer, TopBar, Atmosphere
  screens/       # Dashboard, CalendarScreen
```
